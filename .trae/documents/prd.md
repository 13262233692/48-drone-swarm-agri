## 1. 产品概述

植保无人机集群指挥枢纽平台——面向大面积农场作业的实时指挥调度系统，通过 MQTT 高频遥测链路实现对 50+ 架植保无人机的位置、高度、药箱余量的实时监控，并在卫星底图上渲染 GeoJSON 农田边界与 WebGL 扫掠轨迹，为农场管理者提供全景态势感知与精准作业调度能力。

- 目标用户：大型农场管理者、植保作业调度员、无人机飞手
- 核心价值：将分散的无人机机群数据统一汇聚到一张大屏，实时掌握每架飞机的作业进度与药量状态，避免漏喷/重喷，提升植保作业效率 30%+

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 调度员 | 账号密码登录 | 查看机群态势、下发作业任务、告警处理 |
| 飞手 | 账号密码登录 | 查看分配任务、上报飞行状态 |

### 2.2 功能模块

1. **指挥大屏页**：卫星底图 + GeoJSON 农田边界 + 50 架无人机实时航点 + 扫掠轨迹线 + 药量状态面板
2. **机群列表页**：所有无人机状态表格（在线/离线/低药量/故障）、排序筛选、批量操作
3. **作业详情页**：单架无人机飞行轨迹回放、药量曲线、飞行高度曲线、作业覆盖率

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 指挥大屏页 | 卫星底图与农田边界 | 加载 Leaflet 卫星瓦片底图，叠加 GeoJSON 复杂多边形农田轮廓，支持缩放/平移 |
| 指挥大屏页 | 实时航点图层 | WebSocket 接收 50 架无人机 GPS 坐标，WebGL 绘制动态航点标记，每架用不同颜色区分 |
| 指挥大屏页 | 扫掠轨迹线 | WebGL 绘制半透明宽度的喷洒轨迹，表示已喷洒覆盖面积，支持渐变透明度 |
| 指挥大屏页 | 左侧机群状态面板 | 实时显示在线数量、低药量告警数、故障数，点击可聚焦到对应无人机 |
| 指挥大屏页 | 右侧药量面板 | 每架无人机药箱剩余毫升数进度条，低于阈值红色闪烁告警 |
| 指挥大屏页 | 顶部统计栏 | 总作业面积、已完成面积、平均药量、作业效率等关键指标 |
| 机群列表页 | 状态表格 | 无人机 ID、型号、状态、药量、高度、速度、经纬度、作业进度 |
| 机群列表页 | 筛选排序 | 按状态/药量/高度筛选，支持多字段排序 |
| 作业详情页 | 轨迹回放 | 时间轴滑块，回放单架无人机历史飞行轨迹 |
| 作业详情页 | 传感器曲线 | 药量/高度随时间变化曲线图 |

## 3. 核心流程

用户打开指挥大屏 → 前端建立 WebSocket 连接 → 后端 MQTT 客户端池订阅 `telemetry/#` → 50 架无人机高频心跳（GPS/高度/药量）经 EMQX 透传至 NestJS → NestJS 解析报文并通过 WebSocket 广播至前端 → Leaflet 底图渲染 GeoJSON 边界 → WebGL 图层动态绘制航点与扫掠轨迹 → 调度员实时监控并决策

```mermaid
    "NestJS MQTT 客户端池" -->|"解析/聚合/告警"| "NestJS WebSocket 网关"
    "NestJS WebSocket 网关" -->|"实时推送坐标+药量"| "Vue3 前端"
    "Vue3 前端" -->|"Leaflet 卫星底图"| "GeoJSON 农田边界渲染"
    "Vue3 前端" -->|"WebGL 图层"| "航点 + 扫掠轨迹渲染"
    "Vue3 前端" -->|"状态面板"| "机群药量/告警展示"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色科技风（#0a0e1a 深蓝黑底 + #00e5a0 霓虹绿强调色 + #ff4757 告警红）
- **辅助色**：#1a1f35 面板底色、#2a3155 边框色、#00b8d4 信息蓝
- **按钮风格**：圆角 6px，微发光边框（box-shadow glow），主按钮霓虹绿填充
- **字体**：Rajdhani（数据/数字显示） + Noto Sans SC（中文正文），数字使用等宽特征
- **布局风格**：左右侧栏 + 中间全屏地图，顶部统计条，HUD 风格面板
- **图标风格**：线性描边图标，霓虹色描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 指挥大屏页 | 卫星底图 | 全屏 Leaflet 地图，暗色卫星瓦片，GeoJSON 绿色半透明填充 + 发光边框 |
| 指挥大屏页 | 实时航点 | WebGL Canvas 叠加层，50 个圆形航点（10px），每架独立颜色，脉冲动画 |
| 指挥大屏页 | 扫掠轨迹 | WebGL 宽带状线条，渐变透明度（最新最亮 → 旧最淡），带宽约 8m 喷幅 |
| 指挥大屏页 | 左侧面板 | 深色半透明毛玻璃面板，机群状态卡片，霓虹绿状态指示灯 |
| 指挥大屏页 | 右侧药量面板 | 竖向进度条列表，绿色→黄色→红色渐变，低药量闪烁动画 |
| 指挥大屏页 | 顶部统计栏 | HUD 风格，大号数字 + 单位标签，微发光下边框 |
| 机群列表页 | 数据表格 | 深色背景，行悬停高亮，状态标签带颜色圆点 |
| 作业详情页 | 轨迹回放 | 底部时间轴滑块，播放/暂停按钮，速度选择 |

### 4.3 响应式策略

- 桌面优先（1920×1080 大屏最佳），最小支持 1366×768
- 侧栏面板可折叠，地图始终占据核心视觉区域
- 平板端侧栏自动收起为抽屉式

### 4.4 动效与氛围

- 航点脉冲：每架无人机的航点标记带有缓慢脉冲的发光效果
- 扫掠线渐隐：轨迹线的尾部逐渐淡出，营造"刚刚喷洒"的视觉暗示
- 告警闪烁：低药量/故障状态用 1s 间隔红光闪烁
- 面板滑入：侧栏初始以动画方式从左侧滑入
- 网格扫描线：地图背景叠加微弱的水平扫描线效果（CSS animation）
